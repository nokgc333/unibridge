# ADR-0007: Web UI は信頼できない USD を受け付ける前提で守る

- 状態: 採用
- 日付: 2026-10-27

## 背景

Web UI は USD ファイルのアップロードを受け付ける。USD は参照(sublayer・reference・payload)で他のファイルを読み込めるため、細工したファイルで、サーバー上の任意のファイルを読ませたり、解析を止めたりできる。

## 決定

信頼できない入力として扱い、次の対策を入れる。

| 対策 | 内容 | 応答 |
| --- | --- | --- |
| サイズの上限 | 本文は `Content-Length` で先に判定し、チャンクで読みながら超えた時点で打ち切る | 413 |
| 同時数の上限 | 同時に処理するアップロード数を制限する | 503 |
| 時間の上限 | 解析は別プロセスで実行し、制限時間を超えたら強制終了する | 504 |
| 外部参照の拒否 | 絶対パス・`..`・URL スキームを持つ参照は、開く前に拒否する([ADR-0008](0008-external-reference-policy.md)) | 422 |
| 一時ファイル | 成否にかかわらず削除する | - |
| バインド | 既定は `127.0.0.1` のみ | - |

上限は環境変数で変えられる(`UNIBRIDGE_MAX_UPLOAD_BYTES` など)。

## 理由

- 解析をプロセスごと分けるのは、USD の読み込みが C++ で、Python の例外や時間制限で止められないため
- 上限を環境変数にするのは、利用環境(ローカル・社内サーバー)ごとに妥当な値が違うため

## 結果

- Web UI に認証はない。`0.0.0.0` で公開するときは、認証・TLS・リバースプロキシを別に用意する
- 上の対策は、`tests/test_webui*.py` が個別に確かめている

# ADR-0008: 外部参照は、入力の信頼度で扱いを分ける

- 状態: 採用
- 日付: 2026-10-27

## 背景

USD の参照は、相対パスなら同じ素材フォルダの別ファイルを指す正当な使い方である一方、絶対パス・`..`・URL を使うと、意図しないファイルや外部の資源を読ませられる。CLI は手元のファイルを検査し、Web UI は他人のファイルを受け付ける。

## 決定

`core.stage_loader.open_stage(path, allow_external_references=...)` で、入力の信頼度を呼び出し側が選ぶ。

| 呼び出し元 | 外部参照 | 理由 |
| --- | --- | --- |
| CLI・batch | 許可(既定) | 手元の信頼できるシーンで、素材の参照を解決して検査したい |
| Web UI | 拒否(`ExternalReferenceError`) | 他人のファイルが、サーバーのファイルを読めてはならない |

「外部」とは、URL スキーム(`http:` など)・絶対パス(POSIX と Windows の両方)・`\` や `~` で始まるパス・`..` を含むパスをいう。拒否は、ステージを開く前に、レイヤーの依存(`GetCompositionAssetDependencies`)を見て行う。

`integrity-check` は、解決できない参照を誤りとして報告する([ADR-0006](0006-integrity-checks-without-usdchecker.md))。

## 結果

- 相対パスの参照だけのシーンは、Web UI でも受け付けられる(ただし参照先がアップロードされていなければ、解決できない)
- 判定は文字列だけで行うので、Windows のパス(`C:\...`)も、Linux 上のサーバーで拒否できる
